Script skeleton (internal section order):
```bash
#!/usr/bin/env bash
set -euo pipefail
{ set +x; } 2>/dev/null   # prevent xtrace leaking secret (Pitfall 8, Add 2)

# ---- help ----   (must be FIRST before LABEL is set — Open Question 1 resolution)
case "${1:-}" in
  -h|--help)
    printf 'Usage: pw2agent [label]\n'
    printf '  label  name for the secret (default: secret)\n'
    printf '         writes to ~/.{label}_pw, mode 600\n'
    printf '\nExamples:\n'
    printf '  pw2agent            # stashes as ~/.secret_pw\n'
    printf '  pw2agent api_key    # stashes as ~/.api_key_pw\n'
    exit 0
    ;;
esac

# ---- config ----
LABEL="${1:-secret}"
TARGET="$HOME/.${LABEL}_pw"

# ---- banner ----   (D-11: compact, no fixed-width box)
printf '\npw2agent: stashing "%s" → %s\n\n' "$LABEL" "$TARGET"

# ---- input ----   (D-07: split printf + read -rs; NOT read -rsp)
printf 'Enter secret:   '; read -rs PW1; printf '\n'
printf 'Confirm secret: '; read -rs PW2; printf '\n'

# ---- validate ----   (CORE-03: error if mismatch or empty; nothing written)
if [[ "$PW1" != "$PW2" ]]; then
    printf '❌ Secrets don'\''t match. Nothing written.\n' >&2
    unset PW1 PW2
    exit 1
fi
if [[ -z "$PW1" ]]; then
    printf '❌ Empty secret. Nothing written.\n' >&2
    unset PW1 PW2
    exit 1
fi

# ---- write ----   (CORE-02 + Fix 7: base64-encode; umask before write)
umask 077
printf '%s' "$PW1" | base64 > "$TARGET"
trap 'rm -f "$TARGET"' EXIT INT TERM   # CORE-06: immediately after write
unset PW1 PW2

# ---- confirm ----
BYTES=$(wc -c < "$TARGET")
MODE=$(stat -f '%Lp' "$TARGET" 2>/dev/null || stat -c '%a' "$TARGET")
printf '✅ Stashed at: %s (%s bytes, mode %s)\n\n' "$TARGET" "$BYTES" "$MODE"

# ---- note ----   (D-03: 3 instructions only; Fix 8: base64 -d < file)
AGENT_NOTE="NOTE FOR AGENT — secret handoff
  Label:   ${LABEL}
  File:    ~/.${LABEL}_pw    (mode 600, base64-encoded)
  Read:    PWB64=\$(base64 -d < ~/.${LABEL}_pw | tr -d '\n')
  Delete:  rm -f ~/.${LABEL}_pw"

printf '%s\n\n' "$AGENT_NOTE"

# ---- clipboard ----   (CORE-04: pbcopy/xclip/wl-copy with env-var guards + stdout fallback)
_copy_to_clipboard() {
  local note="$1"
  if command -v pbcopy &>/dev/null; then
    printf '%s' "$note" | pbcopy
  elif [ -n "${DISPLAY:-}" ] && command -v xclip &>/dev/null; then
    printf '%s' "$note" | xclip -selection clipboard
  elif [ -n "${WAYLAND_DISPLAY:-}" ] && command -v wl-copy &>/dev/null; then
    printf '%s' "$note" | wl-copy
  else
    return 1
  fi
}

if _copy_to_clipboard "$AGENT_NOTE"; then
  printf '📋 NOTE copied to clipboard. Paste into your agent.\n'
else
  printf '[No clipboard tool found — copy the NOTE above manually.]\n' >&2
fi

trap - EXIT INT TERM   # file written successfully; disarm cleanup trap
```

Key constraints:
- `rm -f` everywhere — NEVER `rm -P` (D-06, CORE-07, Pitfall 1)
- `printf '%s' "$PW1" | base64 > "$TARGET"` — NOT echo (Pitfall 2, Fix 7)
- `base64 -d < ~/.{label}_pw` — NOT `base64 -d file` (Fix 8, macOS/GNU cross-platform)
- `read -rs` on its own line after `printf 'prompt'` — NOT combined `read -rsp` (D-07, Pitfall 3)
- trap set AFTER write, not before (RESEARCH.md Pitfall 1 / D-05)
- `{ set +x; } 2>/dev/null` on line 3 (Add 2)
- help `case` block BEFORE `LABEL="${1:-secret}"` assignment (Open Question 1)
- Script under 80 lines total (D-09)

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user stdin → shell variable | User enters secret at terminal; read -rs suppresses echo |
| shell variable → file | printf '%s' piped to base64 before write; avoids echo history leak |
| file → clipboard/stdout | NOTE contains path only — never the raw secret |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | `set -x` xtrace in calling shell | mitigate | `{ set +x; } 2>/dev/null` on line 3 of script (Add 2 per RESEARCH.md) |
| T-01-02 | Information Disclosure | echo writes secret to shell history via process argv | mitigate | Use `printf '%s' "$PW1" \| base64` — no echo, no argv expansion |
| T-01-03 | Information Disclosure | `rm -P` no-op leaves secret on disk | mitigate | Use `rm -f` throughout; mode 600 limits read to owner |
| T-01-04 | Information Disclosure | Orphaned secret file on early exit | mitigate | `trap 'rm -f "$TARGET"' EXIT INT TERM` immediately after write |
| T-01-05 | Information Disclosure | Clipboard manager logs NOTE path | accept | NOTE contains path not secret; low-value target; documented in README (Phase 2) |
| T-01-06 | Information Disclosure | `wl-copy`/`xclip` silent fail on headless — user thinks NOTE was copied | mitigate | Env-var guards (`$DISPLAY`, `$WAYLAND_DISPLAY`) + explicit stdout fallback on clipboard failure |
| T-01-07 | Tampering | Predictable temp filename race condition | accept | Script writes to `~/.{label}_pw` (user home, not /tmp); mode 600 set by umask 077 before write |
</threat_model>
