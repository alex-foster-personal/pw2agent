```bash
#!/usr/bin/env bash
set -euo pipefail

# ---- config ----
INSTALL_DIR="$HOME/.local/bin"
SCRIPT_NAME="pw2agent"
SCRIPT_SRC="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)/$SCRIPT_NAME"
RC_FILE="${ZDOTDIR:-$HOME}/.zshrc"
PATH_LINE='export PATH="$HOME/.local/bin:$PATH" # pw2agent'

# ---- main ----
main() {
  # INST-01: create install dir, copy binary, set executable
  mkdir -p "$INSTALL_DIR"
  cp "$SCRIPT_SRC" "$INSTALL_DIR/$SCRIPT_NAME"
  chmod +x "$INSTALL_DIR/$SCRIPT_NAME"

  # INST-02: idempotent PATH append — grep guard prevents duplicate lines
  if ! grep -qF '# pw2agent' "$RC_FILE" 2>/dev/null; then
    printf '\n%s\n' "$PATH_LINE" >> "$RC_FILE"
  fi

  # INST-04: success message
  printf '✅ Ready. Run: pw2agent\n'
  printf '   (open a new terminal or: source %s)\n' "$RC_FILE"
}

# INST-03: main called as last line — safe for partial curl|bash download
main "$@"
```

Key constraints:
- `BASH_SOURCE[0]` resolves install.sh's directory — `cp` copies the adjacent `pw2agent` file
- `grep -qF '# pw2agent'` is the idempotency guard — literal string match (no regex), case-sensitive
- `RC_FILE="${ZDOTDIR:-$HOME}/.zshrc"` — handles non-standard ZDOTDIR (ARCHITECTURE.md anti-pattern #3)
- PATH_LINE contains `# pw2agent` at end — this is what the grep guard matches
- `main "$@"` is the LAST line of the file — nothing after it
- All side-effect commands (`mkdir`, `cp`, `chmod`, `>>`) are inside `main()` — nothing at top level
- `printf` for all output — no bare `echo`
- Phase 1 invocation path is `bash install.sh` from cloned repo (not curl|bash) — document in success message or comment

## Trust Boundaries

|----------|-------------|
| install.sh → ~/.local/bin | Copies script from local repo to user's private bin dir; no network, no escalation |
| install.sh → ~/.zshrc | Appends one PATH line; idempotency guard prevents duplicate writes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | Duplicate PATH lines on re-run corrupt ~/.zshrc | mitigate | `grep -qF '# pw2agent'` guard before any append (D-13, Pitfall 4) |
| T-02-02 | Tampering | Partial curl\|bash execution runs destructive top-level commands | mitigate | All side-effect commands inside `main()`; `main "$@"` is last line (D-15, Pitfall 9) |
| T-02-03 | Information Disclosure | install.sh BASH_SOURCE[0] empty in pure pipe context | accept | Phase 1 invocation is `bash install.sh` from cloned repo only; documented; Phase 2 handles remote URL |
| T-02-04 | Elevation of Privilege | chmod sets world-executable bits | accept | `chmod +x` sets only owner+group+other execute; binary in user's private `~/.local/bin`; no setuid |
